# Legacy client UI lab

This lab preserves the orphaned React/WebGL prototype that once had no valid frontend owner. It is now intentionally project-owned under Desktop Labs rather than buried in porting documentation.

The supported UI remains `src/packages/control-ui/`, hosted by `src/apps/desktop/`. These assets are **not** in its build graph and do not imply runtime support.

Preserved value:

- `NodeGlobe.tsx` — interactive globe/node visualization concept.
- `VantaBackground.tsx` — animated background integration concept.
- `design-tokens.css` — historical visual token set.
- `glassmorphism.css` — historical glass-surface styling reference.

Promotion requires a current UX purpose, dependency and performance review, accessibility/responsive behavior, and rendered regression evidence.
