# Desktop Labs

This directory is the intentional, non-authoritative home for valuable desktop/UI prototypes that are not part of the supported Wails/React application build.

Lab assets may inform future product work, but promotion into the supported desktop/control-UI owners under `src/apps/desktop/` and `src/packages/control-ui/` requires a current product need, dependency review, accessibility/responsive verification, and rendered UI tests. Live frontend code must not import labs directly.

The current catalog is `CAPABILITIES.csv`.
