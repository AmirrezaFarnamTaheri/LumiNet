- **Bounded scanning:** WhiteDNS clean-IP/Android evidence → lazy source enumeration, candidate ceiling, port normalization, ARM32-safe atomics.
- **Truthful transport evidence:** WhiteWarpScout durability + WhiteVPN measured egress → handshake/transient/durable planner with separate advertised/measured geography.
- **DNS reliability/integrity:** CottenDNS presets/FEC/ARQ/resolver observations + WhiteDNS transport evidence → read-only reliability and UDP/TCP integrity planners under existing DNS tunnel/resolver owners.
- **Host proxy correctness:** WhiteAesther/WhiteVPN/WhiteDNS Android → exact host-route release + daemon-owned loopback HTTP→SOCKS compatibility bridge with restore-before-teardown.
- **Provisioning safety:** WhiteDNS Wizard → delegation preflight and atomic managed-generation VPS transaction with rollback.
- **Mobile truth:** WhiteAestherMobile + WhiteDNS Android → closed runtime state and Quick Settings controller while preserving one VpnService authority.
- **Native boundary:** Aether/Aether-whiteaesther → bounded callback wait/nonblocking late delivery and raw FFI pointer/ring validation without importing another runtime registry.
- **Subscription ownership:** WhiteVPN → stable redacted materialized node catalogue, local hide overlay, exact-owner one-node runtime, and TLS failure classification.
- **Operator discoverability:** WhiteAesther settings index → aliases in the existing bounded command palette.
- **Negative relay evidence:** warp-relay → explicit rejection of generic forwarding authority.
