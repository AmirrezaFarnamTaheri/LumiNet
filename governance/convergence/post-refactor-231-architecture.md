# Post-refactor-231 architecture

Five donors are converged over the immutable post-refactor-230 baseline. Mechanical accountability covers **35,331 files**, **8,044 normalized directory/root Merkle records**, **2,163 donor-authored/non-vendored indexed definitions**, **7 archived symlinks**, and **562 module/subtree groups**.

The target retains one live owner per responsibility. New donor semantics are placed into four bounded read-only planners: pluggable-transport lifecycle/admission, bounded circumvention fallback, NaiveProxy compatibility/padding policy, and Stegotorus cover-scheme selection. Existing Naive, Tor, split-tunnel, reconnect and transport runtimes remain authoritative.

NaiveProxy's inherited Chromium snapshot remains fully byte/Merkle-accounted as **33,047 vendored surfaces** but is not misrepresented as Naive-specific semantic innovation.
