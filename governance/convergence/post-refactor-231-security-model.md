# Post-refactor-231 security model

Pluggable-transport planning never starts processes, creates listeners, performs WebRTC/network I/O, or creates state directories. Snowflake and DNSTT do not silently inherit unsupported outbound proxies; unsafe address logging remains explicit. Circumvention fallback is bounded and cannot mutate preferences. Naive compatibility fails closed on SOCKS auth/multi-hop, QUIC-after-TCP, non-Linux redir, IPv6 resolver ranges, and first-CONNECT Fast Open while padding capability is unknown. Stego selection never loads cover assets, embeds payloads, transmits traffic, or mutates success state. Hard-coded application bypass lists, remote auto-configuration, stale donor credentials, post-connect browser redirects, volunteer proxy mode, and duplicate PT/Naive/Stegotorus runtimes are not granted target authority.
