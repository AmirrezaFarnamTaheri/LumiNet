# Ninth-order peer synthesis

## Decision summary
The 20-donor wave converges into four strengthened target-native outcomes rather than twenty donor-shaped subsystems: (1) transactional/CAS config generation, (2) bounded loss-aware WARP quality selection, (3) bounded network-quality diagnostics, and (4) a non-authoritative profile entitlement projection. A dormant unsafe traffic-shaper authority is removed. Privileged deployment scripts, billing/user databases, duplicate Tor helpers, duplicate packet loops and descriptive client catalogs are kept as guardrails/reference evidence.

## Higher-level composition
The panel/bot/server donors agree on an operator need—show quota remaining, expiry urgency and exhaustion—but disagree on database and billing architecture. LumiNet therefore absorbs the user outcome, not the authority: `ProfileEntitlement` is derived from already-owned provider metadata on every read and is explicitly forbidden from granting/revoking/metering connectivity.

Caddy contributes a different higher-level invariant: configuration publication is a generation transaction. The target stages replacement plugins, rolls back partial staging, publishes atomically, retires replaced generations after commit and exposes optimistic whole-config CAS. The Caddy UsagePool is intentionally not generalized into LumiNet until a real resource owner needs reference counting.

The new defyx revision contributes richer diagnostic semantics while its desktop network owner is rejected as duplication. BPB contributes WARP-quality evidence, independently rederived because of GPL licensing. No-license/GPL peer code is not copied.
