# DoH Bypass Blocklist — LumiNet DNS Cluster
# Format: AdGuard-compatible plain domain list (one domain per line, no wildcards).
# Lines starting with # are comments and are ignored.
#
# Purpose:
#   This blocklist contains domains that should bypass DNS-over-HTTPS (DoH)
#   resolution and instead be resolved via the system's native DNS (UDP/DoT).
#   Use cases include:
#     1. Corporate networks that require split-horizon DNS to internal resources.
#     2. Networks that perform deep packet inspection (DPI) on port 53 and block DoH.
#     3. Privacy-sensitive domains where DoH metadata (SNI) leakage is undesirable.
#     4. Anti-censorship: certain domains (e.g. VPN portals, Tor bridges) benefit
#        from opaque DNS via port 53 so their presence is not exposed via DoH SNI.
#
# Sources:
#   Compiled from public blocklists and operator experience. Every entry has been
#   reviewed for correctness and necessity. Submit corrections via the LumiNet
#   issue tracker.
#
# Licence: MIT
# Version: 2024-08
# ---------------------------------------------------------------------------
